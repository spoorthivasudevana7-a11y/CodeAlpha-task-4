MINI PROJECT · PROTOTYPE DESIGN

FoodNow: A Clickable Food Delivery App Prototype

Prototype link: https://claude.ai/artifact/2EayeD33AHkMeWWeA5fHf3

1. Project Overview

FoodNow is a mobile food delivery app prototype. It covers a complete journey: discovering restaurants, choosing dishes, customising an item, reviewing a cart, paying, and tracking the order live. The prototype is fully clickable and reacts to input: filters, search, quantities, coupon and totals all update.

2. Problem and Goals

Problem: Ordering food while hungry and short on time is often slowed by cluttered lists, unclear totals and uncertainty after the order is placed.

GoalHow the design supports it
Fast orderingFew steps, one clear primary button per screen, sticky cart bar
Trust through clarityItemised bill with delivery, coupon and tax lines visible before paying
ReassuranceLive tracking with stages and a countdown ETA
Ease for repeat useFamiliar patterns, bottom navigation, saved address and payment

3. Target User

Ananya, 26, working professional. Orders dinner several times a week on her phone, usually one-handed. Wants a decent meal in under 40 minutes, hates surprise fees, and likes knowing where her order is.

4. Process Followed

Research and persona → user flow → low-fidelity wireframes → high-fidelity UI (colour, type, icons, imagery) → clickable prototype. Earlier stages of this process are documented in the wireframe and high-fidelity pages submitted before.

5. User Flow

Home→Restaurant menu→Item detail→Cart→Checkout→Live tracking→Delivered

Side paths: Home → Search and category filter; Restaurant → favourite; Cart → coupon; Bottom bar → Orders and Profile.

6. Key Design Decisions

Visual style

A warm, appetising look: an orange-red primary for actions and prices, a cream background, and a dark charcoal for text. Rounded cards and soft shadows make touch targets feel obvious.

Typography: Poppins. Bold for headings and prices, medium for labels, regular for descriptions. A small set of sizes keeps hierarchy clear.

UX principles applied

Fitts's law / thumb reachPrimary actions sit at the bottom; targets are about 40px or larger
Hick's lawFew filters, one category at a time, two size options only

Interaction design

  • Item sheet: size and quantity are chosen in one place, and the button shows the live price.
  • Sticky cart bar: appears once an item is added, so checkout is always one tap away.
  • Itemised bill: delivery is free above ₹300, and the coupon FIRST20 gives 20% off up to ₹100.
  • Tracking: the rider icon moves and the steps advance every few seconds to simulate a real order.

8. Testing Plan

The prototype has not yet been tested with real participants. The planned test uses 5 users with this scenario: "Order a pizza and a garlic bread under ₹400 using a coupon, then tell me when it will arrive."

  • Measure: task completion, time on task, wrong taps, and a 1–5 ease rating.
  • Watch for: whether users notice the coupon, understand the size choice, and find the tracking screen.

9. Limitations

  • All restaurants open the same sample menu, and data is simulated. There is no real backend, login or payment.
  • Food images are emoji placeholders rather than photography.
  • The prototype is built as an HTML page, not a Figma or Adobe XD file, so the Figma link is not included.

10. Next Steps

  • Rebuild the screens as frames in Figma using the palette and type scale above and link them with prototype interactions, if a Figma file is required for submission.
  • Add real photography, unique menus per restaurant, and an error state for failed payment.
  • Run the usability test, then iterate on the findings.

11. Conclusion

FoodNow shows how a short, consistent flow with transparent pricing and live feedback can make ordering feel fast and trustworthy. The interactive prototype lets reviewers experience the design rather than only see static screens.
